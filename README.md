# AI Expense Tracker

A modern expense tracking application built with React, Vite, and FastAPI.

## Prerequisites
- Node.js (v18+)
- Python (v3.11+)

## Setup

### Backend
1. `cd backend`
2. `pip install -r requirements.txt`
3. `python run.py` (Server starts at `http://localhost:8000`)

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev` (App available at `http://localhost:5173`)

## Features
- Transaction CRUD operations.
- Monthly dashboard with income/expense/balance.
- Expense category filtering.
- Visual analysis with Recharts.
- Monthly budget management.
